# HEXABOARD

Puzzle de hexágonos com setas, feito em HTML + JavaScript puro (canvas).

- Toque numa peça: ela anda na direção da seta e sai se o caminho estiver livre.
- Se bater em outra peça, desliza e fica parada ali.
- Peças com anel giram 60° quando uma vizinha sai do lugar.
- Pontuação com correntes, vidas e estrelas.

## Jogar
Abra `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.
No celular, use "Adicionar à tela inicial" para instalar como app.
